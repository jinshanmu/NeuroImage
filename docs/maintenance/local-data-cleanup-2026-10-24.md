# 本地数据清理与排除记录

执行日期：2026-10-24（Asia/Shanghai）。状态：**已完成实际删除**，不是仅隐藏入口或将数据移入回收站。

用户授权：安全删除不符合纳入要求的本地数据以释放空间，同步修改软件，并保留记录和排除原因。当前范围为正常人类神经解剖及有依据的正常变异；暂缓眼科、耳科、口腔科/颌面外科专门来源。

## 实际释放空间

- 数据硬盘的可用空间实际增加 **248,296,505,344 bytes = 231.244 GiB ≈ 248.297 GB**。
- 删除 **63个独立来源目录、20,760个文件**，范围仅限已审核的`downloads`、`raw`、`derivatives`具体子目录。
- 另外清除 **576个仅属于排除来源的缓存文件，原占用209.24 MiB**；缓存回执保留。
- 删除前已归档 **772个元数据/清单/说明/源代码记录文件**，压缩包约1.61 MiB，另有本次逐文件台账和删除日志。记录占用SSD，不在上述HDD空间增量内。

数据盘为exFAT且簇较大，实际占用高于文件逻辑字节数；这里使用文件系统实际可用空间差值，不将逻辑大小冒充释放量。

## 保留内容与边界

- HDD上的`licenses`、`literature`、`papers`、`logs`及场景/教学/检查记录保留。
- MIDA、SPL/NAC、Z-Anatomy、BodyParts3D是混合来源，包含仍符合范围的结构，因此保留整库；没有为移除专科方向而破坏共享源模型。
- THU健康志愿者、MUG健康A系列、HCP、CerebrA、CIT168、Julich、SUIT、Brainstem Navigator、BigBrain主数据及合格MASSP研究样本保留。
- 124个旧导出ZIP已检查成员，仅有PNG、JSON、TXT、HTML记录，没有影像体或三维几何负载；按保留记录要求保留。
- 工程备份及32个软件发行归档已检查，未发现内嵌本次排除来源的大型医学数据；保留工程历史、正常模板和合成测试样本。
- 保存的场景、笔记和历史记录不删除。对应数据已清理时无法恢复图谱画面，当前软件会说明排除原因，不再承诺数据包仍在磁盘。

## 安全执行方式

1. 先形成精确路径白名单；验证待删除目录不包含任何当前启用recipe输入或派生包。
2. 对20,760个文件记录路径、大小、占用、时间及文件身份；拒绝软链接、硬链接和非普通文件。本次候选无此类链接。
3. 元数据先归档；检查ZIP CRC、JSON可解析及全部772个保留项存在。20个`.H`文件位于FreeSurfer surf目录，是曲率数据，不当成C语言头文件记录保留。
4. 删除前再次核对整目录文件集合及逐文件身份；任一文件变化则停止。逐个unlink并写删除日志，不使用宽泛根目录通配删除。
5. 删除后核对63个目标目录全部不存在；对照文件系统前后可用空间。独立缓存只删除未与任何保留来源共享的576个二进制文件。
6. 不额外重新计算数百GB原数据的内容hash；既有源checksum及manifest资产hash随记录保留，核对和归档过程不修改数据。
