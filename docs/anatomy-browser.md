# Browse anatomy first

Start the local Linux workspace and open its loopback URL. The home page presents eleven anatomical groups, beginning with **Whole brain**, followed by cortex, deep nuclei, white-matter pathways, ventricles, brainstem, cerebellum, cranial nerves, arteries and veins, cisternal/CSF regions and skull-base context. Select a group's main button to open its deployed atlas directly. Its small source selector offers other datasets covering the same group. Each source keeps its native space and definitions; group membership is not registration or a cross-source identity mapping.

The dataset sidebar shows local deployment and input-file availability. Select a dataset to see its own anatomical groups and source details. **Download, install and build** opens its acquisition, construction and operation tools one level deeper. Opening an atlas verifies its assets. Incomplete builds do not become browse targets. Normal browsing selects the newest complete local package for the chosen source; saved scenes continue to require their exact original package identity.

Click the **NeuroImage** logo to return home. Each new browser page checks the local library once and reuses those results when returning home or navigating through browser history. Reload the page or use **Refresh** in the dataset sidebar to discover external file changes. Dataset operations update the library when acquisition or construction finishes, including when you return home while an operation is running.

## Images and anatomical display

The main workspace prioritizes the canvas. **Structure library** opens the structure drawer. Surface display controls and source references appear in expandable sections below the canvas. A group entry filters the structure list to its delivered source entries; turn off the group checkbox to inspect the rest of that same source.

**Full sections** shows the complete source image field of view. **Magnify at cursor** enlarges the same physical point. The **Panels** selector offers automatic window fitting, a 2 × 2 grid or a horizontal arrangement. Existing scenes without an explicit panel arrangement retain their original grid. Changing presentation does not resample or alter source data.

For small structures, choose **Focus selected 3D**, then **Equal 2D + 3D** in **View layout**. The layout gives the anatomical panel and each of the three native image planes equal display space. Camera focus follows the selected structure's source bounds while the image point and 2D zoom stay fixed. Click a section or double-click a visible surface to explore the same linked physical space. **Full 3D context** restores broader framing. Scene files and image exports retain this layout.

Source notes, references, image-versus-model distinctions and evidence limitations remain accessible. Module engineering and expert-review workflow badges are not displayed in the browsing interface. The corresponding records remain in manifests and internal review files. Hiding a workflow badge does not confer anatomical approval.

## Independent source models

An independent `surface-model` opens a 3D canvas with no fabricated image volume. The display reports **SOURCE_XYZ** coordinates in millimeters; source object names supply laterality, while XYZ axes are not assigned anatomical directions. Compare an MRI in its own native panel when needed. Coordinates, selection and camera state are independent between these panels.

Search and select source objects, show or hide them, add brainstem context, isolate an object, or return to the complete visible model. Drag to orbit, scroll to zoom, and double-click a displayed surface to locate its native point. Source triangles, including broad polygon interiors, determine selection. Hidden, fully transparent and clipped surfaces are excluded. Native XYZ cutaways are display settings; they add no tissue, cap or anatomical boundary.

New model views highlight the selected object in cyan so it remains identifiable among similarly colored branches. **Highlight selected** restores the original source color when disabled. This display setting is saved with scenes and explained in image captions. Older scenes without the setting retain their original colors.

Open **Selected object and surface display** for source geometry, selected opacity and native XYZ cutaway controls. **Sources and coordinates** retains attribution and coordinate definitions. Save scenes in the browser or export portable scene files. Scene import validates the exact package, native coordinate representation, structure IDs and display settings.

**Export image** includes the image, scene, full provenance, renderer record, retained notes and original license/attribution files. It does not include acquired image volumes or model geometry. Retain the exact atlas package to restore exported scenes. Teaching notebooks, courses, learning tools and instructor-review queues remain in the testing branch.

## Engineering evidence

The current browser checks cover every available source configuration, complete initial structure visibility, structure toggles, orthogonal and 3D layouts, same-point 2D magnification and model framing. Workflow checks cover regional backgrounds, cutaway, portable scenes, attributed image exports, independent comparison, expanded viewing and narrow windows. These are software checks; anatomical judgments remain separate.

## Native statistical fields

The vascular group also offers VENAT. Its seven original NIfTI fields open without an invented MRI backdrop or anatomical segmentation. The field selector switches mean, standard deviation and density evidence on demand. Units, statistic and display range remain visible; the secondary library contains the source field definition and unchanged nearest-voxel value. Display contrast does not alter source samples. Source-bound scenes and image exports retain the field identity, units, original attribution and exact package binding.

The SPL/NAC cisternal group opens its source-bound T2 prepontine regional observation anchor in full sections. This entry checks the source version and exact volume grid before using its recorded voxel. The surrounding pons and other labels provide context; the anchor is not a cistern segmentation. Saved scenes retain their own view.

## Dataset navigation and page layout

The home sidebar lists upstream datasets once. Select a dataset to see its cases, regions and source representations on a secondary page; source-specific pages retain acquisition tools and anatomical groups. URLs preserve these selections through reload and browser history. Custom sources remain discoverable as independent dataset entries.

Libraries and browsing controls use the outer browser page scroll. Native select controls display their complete selected text with wrapping, while keeping native keyboard interaction. Browser page zoom and window resizing update the layout and canvas pixel buffer. Fixed-size automation contexts are test instruments and should not be left open as ordinary user windows.
