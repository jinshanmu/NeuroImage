# Browse anatomy first

Start the local Linux workspace and open its loopback URL. The home page presents ten anatomical groups, beginning with **Whole brain**, followed by cortex, deep nuclei, white-matter pathways, ventricles and cisterns, brainstem, cerebellum, cranial nerves, arteries and veins, and skull base. Select a group's main button to open its deployed atlas directly. Its small source selector offers other datasets covering the same group. Each source keeps its native space and definitions; group membership is not registration or a cross-source identity mapping.

**Whole brain** offers SPL/NAC, CerebrA and MIDA packages with source labels across the cerebrum, deep structures, ventricles, brainstem and cerebellum. MIDA supplies categorical tissue and structure classes without MRI or fine cortical parcellation. A full reference MRI alone does not qualify a regional atlas for this entry. CIT168, Brainstem Navigator, Julich-Brain and BigBrain remain available through their regional groups and dataset pages. NextBrain, IXI MRA, HumanBrainAtlas, Meso-vein MRI, VENAT, the Mouches arterial occurrence atlas, Human Inner Ear CT and the clinical TopCoW/TopBrain cohorts are excluded from the current application, including existing package links. Source definitions, licenses, exclusion and inspection records, and saved-scene records are retained. User-authorized removal of out-of-scope data is documented in the [local data cleanup record](maintenance/local-data-cleanup-2026-10-24.md).

Every group's source selector lists datasets that supply its anatomical content. Atlas headings show the title without a source-coverage description; coverage details remain on dataset pages. Hippocampal-only models, isolated cerebellar nuclei, cranial nuclear context and whole-skull backgrounds are offered through detailed topics or their dataset pages. The 52-topic catalog has 46 topics with enabled sources. Five NextBrain-only topics and the former Mouches-only population arterial-occurrence topic have no current browse entry. These sources do not increase the main group's source count. Dataset introductions identify each source's regional scope; their atlas buttons open the complete source package. The [coverage audit](anatomy-group-coverage.md) records the main source lists and anatomical exclusions.

The dataset sidebar opens source introductions and atlas buttons grouped by case or resource. The webpage opens prepared local atlases; acquisition and construction use the [command-line maintenance workflow](local-workspace.md). An unavailable atlas shows a local availability message. Opening an atlas verifies its assets. Incomplete builds do not become browse targets. Normal browsing selects the newest complete local package for the chosen source; saved scenes continue to require their exact original package identity and an enabled source. Scenes and packages from excluded sources cannot be opened through the current application. Saved-scene records are retained without reactivating removed data.

Click the **NeuroImage** logo to return home. Each new browser page checks the local library once and reuses those results when returning home or navigating through browser history. After adding or replacing packages through the CLI, restart the local service and reload the browser to discover the updated library.

While an atlas opens, its canvas shows **Loading** on the canvas's normal opaque background. The rest of the page remains visible. The image and visible source structures appear together when ready for interaction; errors expose a recovery control. Home entries use the exact-package verification endpoint directly. Source assets are read ahead in a bounded queue and installed in their original order; image uploads reuse an already prepared background when only the label palette changes.


The atlas viewer’s top **Source** selector follows the current anatomical group or exact detailed topic. Switching sources retains that category and loads the selected source’s own structure range and URL. Atlases opened directly from a dataset page offer only that dataset family’s representations or cases. An explicitly opened historical package remains selected without adding duplicate versions of the same source.

**Compare sources** uses the same category. **Compare with** offers only other sources that cover the current anatomical group or exact detailed topic; a direct dataset opening uses that dataset family. The primary source is omitted, and comparison is disabled when no other eligible source is available. Each panel loads its own source’s category-specific structure range and keeps its native coordinates, selection and display state. Matching categories do not register the sources or make their anatomical definitions equivalent.

## Images and anatomical display

The main workspace prioritizes the canvas. **Structure library** opens the structure drawer. The **Cutaway** toolbar sits below the canvas and uses the same inline buttons and menus as the other display controls. Source references remain on home dataset pages. A group entry filters the structure list to its delivered source entries; turn off the group checkbox to inspect the rest of that same source.

Categorical `mri-labels` and `label-model` sources use their original label voxels for the default solid 3D display. Cutting through a label exposes its filled voxel interior. Only source-labelled tissue is filled: a cortical gray-matter label does not fill underlying white matter or gaps outside that label. The linked 2D sections remain unchanged. Standalone surfaces without categorical voxels, independent-region data, streamlines and image-only sources retain their existing representations.

**2D overlay** controls the opacity of the supplied section labels or evidence field. **3D opacity** makes colored structures translucent so rear structures can be seen through those in front, with 1 fully opaque and 0 hidden; **3D background** and **2D overlay** remain independent. Both opacity controls start at 50% in new views; saved scenes retain their recorded values. Image-only sources have no label overlay. These display settings do not alter source voxel values or geometry.

Regional entries provide **2D background** and **3D background** sliders for the background available in that source, whose coverage may be partial. Moving a slider to 0 switches off that background; increasing it restores the background at the chosen opacity. Background adjustments preserve the current 3D rotation, center and zoom, including when crossing zero. Categorical sources use their original label voxels as an independently faded gray background under the same **Cutaway**. The background includes the declared brain coverage available in that source, including cerebellum, brainstem, deep structures and ventricles; it does not depend on the foreground selection. Explicit MRI intensity context remains available where supported. The two backgrounds are independent, and their initial display is unchanged: image-backed regional entries show the 2D background at full opacity and leave the 3D background off. Independent surface models offer only their available 3D background. No background setting adds anatomy missing from the source.

The independent **Cursor** checkbox shares the background row and shows or hides the cursor in all linked 2D and 3D panels together. The **Axial**, **Coronal** and **Sagittal** section checkboxes sit immediately to its right, with plain text labels and no separate heading or description. Hiding the cursor preserves the physical location, structure selection and background settings; navigation remains available while the cursor is hidden.

**Cutaway** toggles a 3D cutaway for all currently visible structures. When active, choose the plane and removed side in the toolbar; pressing **Cutaway** again restores the complete structures. New cuts follow the physical cursor as it moves through sections, picks a 3D point or changes RAS coordinates. The active 3D background shares the same cursor-following cut, including when enabled after **Cutaway**. Label volumes show the source-labelled interior along the cut; standalone surface meshes remain open where clipped. There is no separate cut-coordinate input or move-to-cursor action. The cut changes only 3D display clipping; complete source sections and structure visibility remain available. Historical scenes retain fixed cut positions until a new cut is applied.

**2D zoom** and **3D zoom** both offer 1–10 in 0.1 increments and start at 1× in new image workspaces. At 1×, 2D zoom restores the complete source image field of view and clears panning; higher values magnify around the current physical cursor. The 3D factor is relative to the fitted anatomy or full-context framing, so automatic fitting can retain its own native camera scale without changing the factor shown on the slider. Historical scene files keep their recorded camera values. The **Panels** selector offers automatic window fitting, a 2 × 2 grid or a horizontal arrangement. Changing presentation does not resample or alter source data.

The four display sliders provide immediate thumb feedback and submit their latest value once per animation frame. Releasing the control, completing a keyboard adjustment or moving focus commits the final value. Engineering checks distinguish an overlay-opacity change from source, visibility or contrast changes, so opacity-only interaction can use display composition instead of rebuilding source textures. The current control and range updates have syntax and unit coverage; browser performance is assessed separately.

Single-click a 2D section or anywhere in the 3D panel to place the cursor without changing which structures are displayed. Empty and clipped-away 3D locations use a view-parallel plane through the current cursor; navigation is not limited to the source image box. Label-volume hits use the source voxels. Where the source supplies categorical labels, double-click a labelled 2D structure to toggle its display. A hidden structure is shown even when it was outside the entry's initial anatomical group; double-clicking an already displayed structure hides it and clears the active selection. Double-clicking the same 2D point again shows it. Structure visibility is controlled through 2D double-clicks or **Structure library**. Dragging sections, scrolling and entering coordinates also preserve structure visibility. Structure names in **Structure library** continue to select and locate the named structure.

The cursor name is shown once above the canvas and is independent of the active selection and display visibility. Hiding a structure keeps its name at the unchanged cursor position; the readout reports background only when the cursor reaches actual source background. Below the canvas, Image, Layout and Panels appear to the left of the RAS coordinates, with Reset view to their right. Panels appears in the ordinary 2D + 3D layout.

For small structures, select one in **Structure library**, use **Isolate selected** to show it on its own, and adjust **3D zoom**. Choose **2D + 3D** in **View layout** to retain the linked image sections. Use **Panels** to select automatic fitting, a 2 × 2 grid or a horizontal row. Single-click in the 3D panel to place the cursor. Double-click its source-labelled 2D section or use **Structure library** to toggle its display. Historical scenes that used the retired equal layout open as ordinary **2D + 3D** with horizontal panels, while their original files and physical coordinates remain intact.

Source notes, references, image-versus-model distinctions and evidence limitations remain accessible. Module engineering and expert-review workflow badges are not displayed in the browsing interface. The corresponding records remain in manifests and internal review files. Hiding a workflow badge does not confer anatomical approval.

## Independent source models

An independent `surface-model` opens a 3D canvas with no fabricated image volume. The display reports **SOURCE_XYZ** coordinates in millimeters; source object names supply laterality, while XYZ axes are not assigned anatomical directions. When the current category also offers an MRI-backed source, compare it in its own native panel. Coordinates, selection and camera state are independent between these panels.

Search and select source objects, show or hide them, add brainstem context, isolate an object, or return to the complete visible model. Drag to orbit, scroll to zoom, and single-click anywhere in the 3D panel to place the native cursor. Use **Structure library** to show or hide objects. Source triangles, including broad polygon interiors, determine surface hits. Hidden, fully transparent and clipped surfaces are excluded. For these standalone surface models without categorical label voxels, native XYZ cutaways clip the source triangles and add no tissue, cap or anatomical boundary.

New model views highlight the selected object in cyan so it remains identifiable among similarly colored branches. **Highlight selected** restores the original source color when disabled. Historical scenes without the setting retain their original colors when opened through the CLI.

Open **Selected object and surface display** for source geometry and the compact native XYZ cutaway toolbar. **Cutaway** starts a cursor-following cut for all currently visible objects; choosing another 3D point moves the cut on its selected axis. **Reverse cutaway** changes the removed side, and pressing **Cutaway** again restores the complete surfaces. The toolbar has no manual XYZ cut-position input or separate disclosure menu. **3D opacity** adjusts the complete displayed model. The model retains its native coordinate readout, status row and selected-object controls. Choose its dataset on the home page for the source introduction, attribution, coverage and coordinate definitions.

## Dataset navigation and page layout

The home sidebar lists upstream datasets once. Selecting one opens **About this dataset**, followed by **Atlases** grouped by the original case, specimen or population resource. Each atlas button opens its complete source package directly. Dataset pages do not insert anatomical groups or a separate configuration-selection page before opening an atlas. The main anatomy page retains its group and detailed-topic routes.

Representations of the same source share a case card: MUG500+ A0101 has original skull labels and an author-cleaned surface; the BigBrain specimen has cortical laminar and hippocampal models; HCP1065 has population streamlines and probability fields. THU's eight volunteers remain separate cases. A population resource is labeled as an atlas rather than an individual participant. Each atlas retains its own native coordinates and representation.

**Source coverage and coordinates** contains source references, licenses, native spaces, acquisition information and coverage limits. Choose the dataset from the home sidebar to access that information. Official source and license links remain available. Source acquisition and atlas construction are CLI maintenance tasks. Existing dataset URLs resolve to the corresponding dataset detail, and browser history preserves navigation. Custom sources remain discoverable as independent dataset entries.

Libraries and browsing controls use the outer browser page scroll. Native select controls display their complete selected text with wrapping, while keeping native keyboard interaction. Browser page zoom and window resizing update the layout and canvas pixel buffer. Fixed-size automation contexts are test instruments and should not be left open as ordinary user windows.
