# Browse normal anatomy and variation

The formal release focuses on linked anatomy browsing. Guided lessons, learning records, notebooks and courses remain in `codex/release-testing`.

## Explore a source

Choose an anatomical group or detailed topic, select a structure in **Structure library**, and inspect it in the linked sections and 3D view. The current 398-object selection remains available under the original Z-Anatomy source, including cortical, dural, deep nuclear, brainstem, cerebellar and ventricular context. Its original source geometry uses independent XYZ coordinates.

Enabled cerebellar probabilities, white-matter trajectories, native MRI and independent anatomical models remain distinct representations. A topic's presence reflects the actual available source structures.

## Compare normal arterial variation

Ten healthy-volunteer Cerebral MRA cases remain available: 001, 006, 007, 009, 010, 014, 015, 019, 021 and 030. Open a source and enable **Compare sources** to inspect another case. Each panel keeps its own position and display state.

The full 109-case inventory and earlier validation records are archived source evidence. They do not expand the current ten-case selection. The selected original inputs remain complete; current use does not require downloading the removed full-cohort archives.

1. Select corresponding regions using each source's structures.
2. Follow the represented vessel across adjacent sections and rotate the 3D context.
3. Adjust label opacity against the original image signal.
4. Inspect another eligible source in the same category while retaining each panel's native coordinates. Scene-saving and image-export tools remain in `codex/release-testing`.

The source supplies registered, cropped MRA and numeric segment annotations. A missing label alone does not establish a named anatomical variant. Population occurrence and probability fields remain separate from individual examples.
