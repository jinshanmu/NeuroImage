# Browse normal anatomy and variation

The formal release focuses on linked anatomy browsing. Guided lessons, learning records, notebooks and courses remain in `codex/release-testing`.

## Explore a source

Choose an anatomical group or detailed topic, select a structure in **Structure library**, and inspect it in the linked sections and 3D view. The complete 350-object Z-Anatomy selection remains available, including cortical, dural, deep nuclear, brainstem, cerebellar and ventricular context. Its original source geometry uses independent XYZ coordinates.

NextBrain tissue blocks, cerebellar probabilities, inner-ear CT, white-matter trajectories and native MRI remain distinct representations. A topic's presence reflects the actual available source structures.

## Compare normal arterial variation

Eight healthy-volunteer Cerebral MRA cases remain available. Open a source and enable **Compare sources** to inspect another case. Each panel keeps its own position and display state.

1. Select corresponding regions using each source's structures.
2. Follow the represented vessel across adjacent sections and rotate the 3D context.
3. Adjust label opacity against the original image signal.
4. Save or export scenes and credited images for further inspection.

The source supplies registered, cropped MRA and numeric segment annotations. A missing label alone does not establish a named anatomical variant. Population occurrence and probability fields remain separate from individual examples.

See the [MRA source guide](thu-cerebral-mra.md) and [anatomical roadmap](release-scope-and-roadmap.md).
