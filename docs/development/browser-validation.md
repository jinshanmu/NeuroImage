## Diagnosed failures retained

- Initial sparse source values reached 60004, exceeding a software WebGL renderer's palette texture dimension. In-memory dense palette indexing fixed this without changing the source IDs, arrays or affines. Two palette regression checks cover sparse indexing and invalid values.
- The OS Snap Chromium browser rendered correctly, but Playwright download paths crossed the Snap-private temporary filesystem and `download.saveAs` returned `ENOENT`. The identical export workflow passed in the isolated non-Snap Chromium runtime. No application export workaround or source-data duplication was necessary.
- Tiny symbolic-link acquisition checks require a filesystem supporting symbolic links. This workstation's HDD does not support them, so only that text-only test uses the system temporary directory; imaging fixtures remain on the data drive.
- NiiVue's default `meshThicknessOn2D=Infinity` projects complete surfaces into 2D windows. Explicitly setting it to zero keeps those windows faithful to their actual categorical slice. Earlier numeric coordinates and source meshes remained valid, but earlier screenshots were superseded for slice-boundary review. Actual-pixel comparisons now check that surface opacity cannot change a 2D-only view and that label visibility/opacity does change its categorical pixels. Exports carry the exact viewer source fingerprint and rendering policy.
- The base-slice shader ignores per-label alpha. Categorical model visibility therefore also zeroes hidden labels' display RGB, without altering their categorical arrays. Global section opacity remains independent of three-dimensional surface opacity.
- NiiVue 0.69.0's generic TCK reader overwrites the first trajectory offset; its fiber pass also ignores individual bundle visibility and opacity. The explicit canonical TCK reader retains every line boundary, and the trajectory draw pass applies actual per-bundle state and physical slab matrices. Fixed colors disable its default directional coloring and random dither. A truthy negative minimum length avoids the renderer's zero-value early return without dropping any source trajectory.
- A previously selected trajectory overlap could remain in the inspector after its bundle was hidden. Proximity evidence now refreshes after visible geometry and display sampling settle, preserving the physical section axis used for 2D picks. A real CC/CST_L overlap fixture exercises that state transition.
